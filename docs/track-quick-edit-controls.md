# Track Quick Edit Controls

Quiet Light now supports editing existing tracks from the admin music section.

## Route

`/admin/music`

## Editable fields

- Album assignment
- Title
- Slug
- Description
- Track number
- Status
- Embed URL

## Status controls

Track cards can now be moved through:

- Draft
- Published
- Archived

## Workflow

1. Open `/admin/music`.
2. Find a track card.
3. Click **Edit Track**.
4. Update the track information.
5. Save the track.
6. Publish, move to draft, archive, or restore as needed.

## Album readiness

Publishing a track can now satisfy the album publishing guard that requires at least one published track.
