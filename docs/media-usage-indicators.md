# Media Usage Indicators

Quiet Light now shows where media assets are used.

## Route

`/admin/media`

## Usage checks

The media library checks recent media assets against:

- Product cover images.
- Blog post cover images.

## Card display

Each media card now includes a Usage section.

When usage is detected, the card links to the related product or blog post.

When no usage is detected, the card shows that no linked usage was found.

## Summary

The top of the media library shows how many listed assets are currently linked to products or posts.
