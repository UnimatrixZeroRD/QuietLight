# Draft Group Actions

The admin dashboard now has group-level draft actions.

## Route

`/admin`

## Included cards

- Blog drafts
- Daily Light drafts
- Product drafts
- Album drafts

## Actions

Each stale draft group can now be handled as a set.

- Keep All Drafts refreshes the stale draft timestamps for that group.
- Archive All changes the stale drafts in that group to archived status.

Individual stale draft actions remain available for one-at-a-time cleanup.
