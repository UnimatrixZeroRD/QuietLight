# Track Publishing Guards

Quiet Light now blocks track publishing until a track is ready.

## Route

`/admin/music`

## Required before publishing

A track must have:

- Title
- Slug
- Album assignment
- Track number
- Embed URL

## Admin behavior

Track cards now show a readiness panel.

The **Publish** button is disabled when required details are missing.

The quick edit form also blocks saving a track as published when the readiness check fails.

## Summary

The top of the track list shows how many tracks are ready and how many need review.
