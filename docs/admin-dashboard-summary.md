# Admin Dashboard Summary

Quiet Light now includes summary cards on the admin home page.

---

## Route

- `/admin`

---

## Dashboard Cards

The dashboard shows:

- Pending orders.
- Open messages.
- Completed purchases and completed revenue total.
- Delivery-ready products and products needing attention.

---

## Recent Activity

The dashboard also shows recent activity from:

- Orders.
- Messages.
- Purchases.

Each activity item links to the relevant admin section.

---

## Purpose

The dashboard gives a fast launch-readiness view of the platform without opening every admin tool separately.
