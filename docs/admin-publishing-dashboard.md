# Admin Publishing Dashboard Counts

Quiet Light now shows publishing and content counts on the admin home dashboard.

---

## Route

- `/admin`

---

## Added Counts

The admin dashboard now includes:

- Published blog posts and draft blog posts.
- Published Daily Light entries and draft Daily Light entries.
- Active products and draft products.
- Published albums and draft albums.
- Total profiles and admin profiles.

---

## Existing Dashboard Counts

The dashboard also continues to show:

- Pending orders.
- Paid orders awaiting review.
- Open messages.
- Completed purchases.
- Completed revenue total.
- Delivery-ready products.
- Products needing delivery attention.
- Recent order, message, and purchase activity.

---

## Purpose

This turns the admin home page into a launch-control overview. Before a public launch, the admin can quickly see whether content, products, delivery, orders, messages, and user profiles are in a healthy state.
