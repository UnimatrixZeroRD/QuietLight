# Admin Public Album Links

Quiet Light now links published albums from the admin music section to their public album pages.

## Route

`/admin/music`

## What changed

Published album cards now show:

- An inline public page link below the cover alt text status.
- A **View Public Page** action beside the edit and status controls.

Draft and archived albums show a note that the public page is available after publishing.

## Public route

Published albums link to:

`/music/[slug]`

## Why this matters

Admins can now quickly verify the live album page after publishing or editing album content.
