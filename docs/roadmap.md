# Roadmap

This roadmap outlines the planned phases for building the Quiet Light website.

The goal is to move from documentation to a polished public website in controlled stages.

---

## Phase 0 — Repository Setup and Documentation

Status: **In progress**

Goals:

- Create repository.
- Fill out README.
- Add project documentation.
- Define design direction.
- Define technology stack.
- Define site architecture.
- Define asset and content strategy.

Deliverables:

- `README.md`
- `docs/project-overview.md`
- `docs/site-architecture.md`
- `docs/design-system.md`
- `docs/technology-stack.md`
- `docs/content-and-assets.md`
- `docs/development-workflow.md`
- `docs/deployment.md`
- `docs/roadmap.md`

---

## Phase 1 — Website Scaffold

Status: **Planned**

Goals:

- Create Next.js project.
- Enable TypeScript.
- Add Tailwind CSS.
- Configure basic project structure.
- Add global styles.
- Add project metadata.

Deliverables:

- Working local development server.
- Initial app routes.
- Basic page shell.
- Global CSS and Tailwind configuration.

Success criteria:

- `npm run dev` works.
- `npm run build` works.
- Homepage route loads.
- Project can be deployed to Vercel.

## Phase 2 — Design System Implementation

Status: **Planned**

Goals:

- Add blue/gold color palette.
- Add typography choices.
- Create button styles.
- Create card styles.
- Create dividers and ornament styles.
- Create reusable layout components.

Deliverables:

- Header component.
- Footer component.
- Button component.
- Section heading component.
- Card component.
- Hero component.
- Album card component.
- Quote card component.

Success criteria:

- Components are reusable.
- Mobile and desktop styling are considered from the beginning.

Homepage sections:

2. What Is the Way of Quiet Light?
3. The Keeper's Lantern.

The next best development step is:
