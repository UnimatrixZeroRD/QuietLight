# Album Cover Alt Text

Quiet Light now supports cover alt text for albums.

## Live database

The live database now includes:

- `albums.cover_alt_text`

## Route

`/admin/music`

## Admin support

Album cards now show cover alt text status.

The album quick editor now lets admins save cover alt text.

If an album has a cover image but no cover alt text, the album card shows a review warning.

## Next
