# Live Page Validation Cards

The admin dashboard now includes live-page validation cards.

## Route

`/admin`

## Checks

The dashboard checks these live routes:

- Blog pages
- Daily Light pages
- Store pages
- Album pages

## Validation

Published or active items are checked for missing public-page details such as:

- Title
- Slug
- Summary or description
- Cover or featured image
- Alt text where applicable
- Publish date where applicable

## Actions

Each card links to the matching admin list.

The first few items needing review also link directly to the public route so the live page can be checked quickly.
