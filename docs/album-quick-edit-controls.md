# Album Quick Edit Controls

Quiet Light now supports editing existing albums from the admin music section.

## Route

`/admin/music`

## Editable fields

- Title
- Subtitle
- Slug
- Description
- Cover image
- Status

## Status controls

Album cards can now be moved through:

- Draft
- Published
- Archived

## Workflow

1. Open `/admin/music`.
2. Find an album card.
3. Click **Edit Album**.
4. Update the album information.
5. Choose or paste a cover image.
6. Save the album.
7. Publish, move to draft, archive, or restore as needed.
