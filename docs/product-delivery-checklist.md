# Product Delivery Checklist

Quiet Light now includes an admin delivery checklist at:

- /admin/delivery

---

## Purpose

The checklist helps confirm whether store products are ready to be delivered to customers after purchase.

It highlights:

- Products with no attached files.
- Products with attached files missing customer-facing descriptions.
- Products that appear ready for delivery.

---

## Status Rules

- Ready: the product has at least one attached file and each attached file has a description.
- Needs files: the product has no attached files.
- Needs descriptions: the product has files, but one or more descriptions are blank.

---

## Recommended Use

Before making a product active or promoting it publicly:

1. Upload the product file in Admin Media.
2. Attach the file in Admin Products.
3. Add a clear file title and description.
4. Open /admin/delivery.
5. Confirm the product shows Ready.
6. Test purchase, fulfillment, account library, and signed download.
