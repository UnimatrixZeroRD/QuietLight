# Editable Media Assets

Quiet Light now supports editing existing media records from the admin media library.

## Route

`/admin/media`

## Editable fields

- Title
- Description
- Alt text
- Bucket
- Path
- Media type
- Access level

## Image preview

Public image records can show a preview in the media asset card.

## Workflow

1. Open `/admin/media`.
2. Find an existing media record.
3. Click **Edit Asset**.
4. Update the relevant fields.
5. Click **Save Asset**.
6. Refresh or confirm the card updates.
