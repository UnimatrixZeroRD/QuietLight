# Product Cover Selection

The product quick editor can now choose a cover image from the existing image records.

## Route

`/admin/products`

## Flow

1. Add an image in `/admin/media`.
2. Open `/admin/products`.
3. Click **Edit Details**.
4. Choose a cover image.
5. Check the preview.
6. Save the product.
7. Open the store page and confirm the cover appears.

## Fallback

A manual URL field remains available when a cover image is not listed in the picker.
