# Daily Light Public Pages

Quiet Light now has public Daily Light list and entry pages.

Routes:

- `/daily-light`
- `/daily-light/[slug]`

---

## Current Flow

1. Create a Daily Light entry in `/admin/content`.
2. Set the entry status to Published.
3. Open `/daily-light`.
4. The latest entry appears at the top.
5. Published entries appear in the archive grid.
6. Each entry links to its own detail page.

---

## Detail Page Fields

The detail page can show:

- Title.
- Published date.
- Scripture reference.
- Scripture text.
- Reflection.
- Prayer.
