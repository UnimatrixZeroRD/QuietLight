# Album Media Usage

Quiet Light now checks media asset usage against album cover images.

## Route

`/admin/media`

## Usage checks

The media library now checks listed assets against:

- Product cover images.
- Blog post cover images.
- Album cover images.

## Album links

Album cover usage links back to `/admin/music`, where album records are managed.

## Archive safety

Images used by albums are now included in the media archive safety check.
